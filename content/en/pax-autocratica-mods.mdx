## Safe checks before any future install

When a supported mod path eventually appears, the first job is source verification, not speed. Confirm that the download comes from the announced or clearly traceable distribution source, that the package names the game version it supports, and that the instructions match the current Steam installation. Do not assume a popular archive is safe simply because other players mention it.

Backups matter because a colony sim can retain progress in save files that a mod changes indirectly. Keep a copy of saves outside the game directory, record the original build, and make one change at a time. If a mod changes the game's executable, asks for unrelated permissions, or provides no version/rollback information, treat that as a stop signal.

1. Back up saves before changing any game files.
1. Record the current Steam build and the exact tool/package version.
1. Read the complete installation and removal instructions before copying anything.
1. Test one package at a time and keep a clean rollback path.
