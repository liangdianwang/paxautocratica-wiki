# Pax Autocratica Camera Height Setting

Pax Autocratica now has a First-Person Camera Height setting. The October 16 OT-16 patch says it lets Leaders customize first-person viewpoint height. If the view feels too low, open the in-game settings and look for that named setting; change only that control, then retest the same scene. The public patch note does not state a numeric range, a default value, or a universal best height.

## Why this setting exists

Players have repeatedly described the first-person view as too low in the Steam discussion “Camera too low?”. That thread has a moderator-marked answer about testing an adjustable camera view. OT-16 now confirms the shipped First-Person Camera Height setting.

The official patch says the control customizes viewpoint height. It does not document whether it changes FOV, third-person camera, aiming behavior, collision, movement, or accessibility presets.

1. Update Pax Autocratica to the current build.
2. Open Settings while in-game and find First-Person Camera Height.
3. Change that one setting and revisit the same base or expedition scene.
4. Keep the result that makes the view comfortable without treating it as a required competitive setting.

## A safe way to test it

Use a repeatable scene so that UI scale, brightness, FOV, vignette and camera height are not all changed at once. If the result still feels wrong, record the scene and the setting state for a focused report instead of installing an unverified mod or editing files.

This is separate from the darkness-vignette page. OT-16 also adds a Vignette setting, but the patch gives no basis to say that camera height fixes edge darkening, ultrawide blur, performance, or every accessibility concern.

1. Note your current camera height before changing it.
2. Test in one stationary scene, then one combat/expedition scene.
3. If the problem remains, report the build and scene through the official support route.

## What this guide does not claim

This page does not invent slider values, keybinds, a preset name, a camera mod recommendation, or a guarantee that all players can remove the low-view feeling. It only records the setting named in OT-16 and the player task that prompted it.

Recheck this page if Multiverse publishes a more detailed control description or a later patch changes the setting.

1. Do not assume a number is optimal for every display or player.
2. Do not treat old discussion replies as newer than the live OT-16 patch.
3. Do not use this page as evidence about field of view or third-person camera.

## FAQ

### Can I raise the first-person camera in Pax Autocratica?

OT-16 adds a First-Person Camera Height setting. Open in-game settings and adjust that named control.

### What is the best camera height?

No official source captured today gives a recommended value or range. Test it in the same scene and use the height that is comfortable for you.

### Does camera height fix the dark vignette?

No. OT-16 names both settings, but does not say one fixes the other.
